# DevPrompt Lab

An open-source AI developer tool for testing prompts, comparing model outputs, and experimenting with structured AI workflows.

## Status
Early-stage open-source developer project.

## Planned features
- Prompt workspace
- Model/provider configuration
- Prompt versioning
- Output comparison
- Structured JSON testing
- Claude API integration
- Usage tracking

## Local development

```bash
npm install
npm run dev
```

The first version intentionally runs as a lightweight local web app. API credentials should be stored in environment variables and never committed to Git.
